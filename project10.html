Water Tank Filling & Discharge Control Using Node-RED

Project Overview

This project presents a complete water tank filling and discharge control system developed without using a traditional PLC. Instead, the entire control logic was implemented using Node-RED, while the industrial process was simulated on Factory I/O and connected through Modbus TCP/IP communication. The goal was to demonstrate how modern software-based solutions (Soft PLC concept) can replace conventional PLCs for small and medium automation systems with lower cost and higher flexibility. Node-RED acted as the system “brain,” reading sensor data and writing control commands directly to the field devices via Modbus registers.

System Operation

    The system controls both filling and discharge valves with safe and practical industrial logic: Filling / Discharge Control,

    Each valve has:

  • Start button.
  • Stop button.
  • Slider (0–100% opening).

    • Logic behavior:

  • Press Start → slider becomes active and sends valve opening percentage.
  • Press Stop → valve closes immediately (0%) and further control is disabled.
  • No command is accepted again until Start is pressed.
  • This prevents accidental valve operation and improves safety.
  • Monitoring & Alarms

    • The dashboard displays:

  • Real-time flowmeter graph
  • Tank level states: LL, L, H, HH
  • High-level alarm with sound and message: “Warning: High Level Water”
