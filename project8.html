Control Building

📑 Project Description

Project Overview

This project involved the complete electrical design of a control building consisting of a ground floor and a roof. The system design adhered strictly to the Egyptian code.

My Role

My personal contribution was handling the entire project design process. This included ensuring proper lighting distribution, power system and load management, fire alarm system, light current, cable tray, scheduals , sld and rizers.

System Distribution

Systmes are distributed and documented on Revit. Each system had a separate lighting and power panel and circuits were connected appropriately. schedules were created, and circuit protection was applied based on Egyptian standards.

Types of Fixtures Used:

  • Circular LED (IP20/IP44)
  • Ceiling Mounted Linear LED Profile (IP44)
  • Wall Mounted Circular
  • Magnetic Track
  • Pendant LED Linear (IP44)
  • Circular Suspended LED
  • Exit Sign

Tools Used

  • DIALux Evo for lighting simulation
  • Revit for Design and layout
